⚡ Multithreaded Java HTTP Server

Built completely from scratch using raw TCP Sockets & Concurrency primitives

Features Implemented

  • Raw TCP Sockets — ServerSocket & Socket (no Netty/Spring)
  • RFC 7230 Parser — Custom stream parser for request-line, headers & body
  • Concurrency — Thread pool execution with configurable worker threads
  • Persistent Connections — HTTP/1.1 Keep-Alive with idle read timeouts
  • Routing Engine — Method + path dispatch, 404 Not Found, 405 Method Not Allowed
  • Static File Serving — MIME type resolution with directory traversal protection
